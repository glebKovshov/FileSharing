# FileSharing

Приложение для обмена файлами между компьютерами Windows в локальной сети.
Интерфейс написан на C++/CLI и Windows Forms. Устройства обнаруживаются через
UDP broadcast (порт 12345), файлы передаются по TCP.

## Сборка

Требования: Windows, Visual Studio 2022 с компонентами разработки на C++,
поддержкой C++/CLI для инструментов v143, Windows SDK 10 и .NET Framework 4.7.2
Developer Pack.

1. Откройте `FileSharing.sln` в Visual Studio.
2. Выберите конфигурацию `Debug` и платформу `x64`.
3. Соберите решение и запустите приложение.

## Использование

1. Подключите оба компьютера к одной локальной сети и запустите приложение.
2. На принимающем компьютере откройте режим приёма.
3. На отправляющем компьютере откройте режим отправки и выберите файл.
4. На принимающем компьютере выберите обнаруженное устройство и подтвердите
   подключение.

Полученные файлы сохраняются в `%LOCALAPPDATA%\FileSharing`.
Разрешите приложению доступ к локальной сети в брандмауэре Windows:
для обнаружения используется UDP 12345, TCP-порт приёма назначается системой.
